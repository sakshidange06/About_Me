# 🌟 About Me - Personal Web Page

A simple and responsive personal profile web page built with **HTML5** and **CSS3** as part of learning web development fundamentals.

## 🚀 Main Features

* **Styling & Design:** Clean, centered layout with a custom color palette (`lightblue` background and `darkblue` headings).
* **Profile Image Styling:** Features a customized profile picture with a solid black border, margin, and padding.
* **Structured Content:** Organized introduction divided into concise paragraphs sharing background, interests, and hobbies.
* **Internal CSS:** Uses embedded styles within the `<style>` tag for easy portability and styling control.

## 🛠️ Technologies Used

* **HTML5:** For structuring the page content (`<h1>`, `<p>`, `<img>`).
* **CSS3:** For styling and visual presentation (`background-color`, `color`, `text-align`, `border`).
